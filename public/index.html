알고리즘 원리

AI 이미지 판별 알고리즘

실제 사진과 AI 생성 이미지의 물리적 차이를 수학적으로 분석합니다

01

밝기 정보 추출 Luminance

L(x,y) = 0.2126·R + 0.7152·G + 0.0722·B

사람이 인식하는 밝기 기준에 따라 R, G, B를 가중 합산하여 밝기 L을 생성합니다. 녹색 채널이 가장 큰 가중치를 가집니다.

02

이미지 기울기 계산 Gradient

Gx = ∂L/∂x  ,  Gy = ∂L/∂y

Sobel 필터로 x, y 방향의 밝기 변화율을 계산합니다. 엣지 정보를 추출하며, AI 이미지는 이 패턴이 비자연적입니다.

03

각 픽셀의 벡터 구성 Vector

v(x,y) = [Gx, Gy]T

모든 픽셀마다 Gx, Gy를 묶어 2차원 벡터로 구성합니다. 이미지의 방향성 정보를 포착합니다.

04

데이터 평탄화 Flatten

M = [v₁, v₂, ..., vN]T ∈ ℝN×2

전체 이미지를 1차원으로 펴서 2열 행렬로 변환합니다. N은 전체 픽셀 수입니다.

05

공분산 행렬 계산 Covariance

C = (1/N) · MTM

이미지 전체의 기울기 패턴 분포를 수학적으로 분석하는 핵심 단계입니다.

06

판별 기준: Trace(C) PCA

Trace(C) = C00 + C11

공분산 행렬의 대각합을 기준으로 이미지의 패턴 복잡도를 판단합니다. 실제 사진은 높고 AI 이미지는 낮습니다.

07

AI 의심도 점수 계산 Score

점수 = min(100, Trace(C) / 12)

Trace 값을 기반으로 0~100%로 변환하여 직관적으로 표시합니다. 추가로 그라디언트 이방성, 채도 분산, 고주파 비율을 복합 분석하여 최종 AI 확률을 산출합니다.

0~35% 실제 사진 가능성 높음
35~60% 불확실 (추가 검증 필요)
60~100% AI 생성 가능성 높음

실제 사진 vs AI 생성 이미지의 차이

📷 실제 사진
  • 실제 빛과 카메라 센서로 촬영
  • 색상 변화가 자연스럽고 일관적
  • 물리 법칙을 따르는 안정적인 패턴
  • 높은 Trace(C) 값 (복잡한 텍스처)
  • 일관된 방향성의 그라디언트
🤖 AI 생성 이미지
  • 노이즈에서 점진적으로 생성되는 과정
  • 색상 변화가 불안정하고 불규칙적
  • 고주파 영역에서 부자연스러운 구조
  • 낮은 Trace(C) 값 (과도한 평탄화)
  • 비일관적인 그라디언트 분포
